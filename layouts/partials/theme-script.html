The button in the header (header.html, theme-toggle) switches to the other scheme than the one shown; the choice is kept in localStorage under "theme" and set as data-theme on the html element, unless it is the scheme of the system, in which case the choice is forgotten and the page follows the system again. The class theme-switch on the html element shows the button (50-header.css): without scripts it could not do anything.
