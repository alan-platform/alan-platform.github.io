{{- /* Language documentation table of one platform version, (dict "version" V "caption" B), where V is an entry of _data/versions.json. Platform component versions come from that entry, system type versions from _data/dist//versions.json, both in the order of their file. The rows come from the documentation pages themselves, see doc-rows.html. With caption, the table names its platform version first, linking its release notes when it has them.
